Style Spy

See a website's main colours and fonts in one click, save them as a kit, and export CSS variables. Nothing is sent anywhere. Everything runs in your browser.

Demo page. A web page cannot read other websites, so this page scans the sample sites below (or your own HTML). The real tool for any website is the Chrome extension: see the install steps at the bottom.

1. Pick a site to scan

Paste your own HTML and CSS

2. Colours ranked by use on screen. Click to copy.

Fonts click a row to copy its CSS

3. Save as a kit
